# Dashboard Overview

## Overview

This document provides an overview of the security dashboards developed in Splunk Enterprise using Microsoft Sysmon event logs. The dashboards offer real-time visibility into Windows endpoint activity, helping Security Operations Center (SOC) analysts monitor system behavior, identify suspicious events, and support incident investigation.

---

## Dashboard 1 – Sysmon Monitoring Dashboard

### Purpose
Provides a centralized overview of Windows Sysmon events collected and indexed by Splunk Enterprise.

### Key Insights
- Real-time endpoint activity monitoring
- Centralized security event visibility
- Event trend analysis
- Improved threat monitoring

---

## Dashboard 2 – Top 10 Executed Processes

### Purpose
Displays the top ten most frequently executed processes captured through Sysmon Event ID 1.

### Key Insights
- Frequently executed applications
- Process execution trends
- Detection of unusual process activity
- Endpoint process visibility

---

## Dashboard 3 – Top Users Creating Processes

### Purpose
Identifies the users responsible for generating process creation events across monitored Windows endpoints.

### Key Insights
- User activity monitoring
- Process ownership analysis
- Privileged account visibility
- Investigation of suspicious user behavior

---

## Dashboard 4 – Total Process Creation Events

### Purpose
Displays the total number of process creation events collected from Windows endpoints.

### Key Insights
- Overall process activity
- Endpoint monitoring statistics
- Security event volume
- Baseline process analysis

---

## Dashboard 5 – Network Connections

### Purpose
Monitors network connection events generated by Sysmon to provide visibility into endpoint communication.

### Key Insights
- Outbound network connections
- Suspicious communication detection
- Endpoint network activity
- Threat hunting support

---

## Dashboard 6 – DNS Queries

### Purpose
Displays DNS query events recorded by Sysmon, enabling analysts to monitor domain resolution activity.

### Key Insights
- DNS request monitoring
- Domain resolution visibility
- Detection of suspicious domains
- Investigation of potential command-and-control activity

---

## Conclusion

These dashboards demonstrate the practical implementation of Splunk Enterprise as a Security Information and Event Management (SIEM) solution. By collecting and visualizing Microsoft Sysmon logs, they provide SOC analysts with actionable insights for monitoring endpoint activity, detecting suspicious behavior, and supporting effective incident response.
